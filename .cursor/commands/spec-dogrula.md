# /spec-dogrula — Kanal spec doğrulama

## Objective
Görsel/asset dosyasını MATRIX spec'lerine karşı doğrula.

## Requirements
- Hedef dosya yolu veya CANVA export
- `python3 scripts/spec_validate.py <path>`
- Skill: `spec-matrix`

## Output
- PASS/FAIL özeti
- `CANVA_OPS/VALIDATION.log` girişi
- Düzeltme önerileri (boyut, ratio, safe zone)
