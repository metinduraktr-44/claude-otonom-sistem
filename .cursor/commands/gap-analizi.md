# /gap-analizi — Güvenlik boşluk analizi

Mevcut envanter vs hedef kontrollere (6×100 iskelet / NIST CSF) gap üret.

## Requirements
- Kaynak: `SECURITY_CONTEXT/`, `SECURITY_MATRIX/matrix.md`
- Defense-only; exploit adımı yok
- Bulguları severity + önerilen kontrol ID ile yaz

## Output
`ASSESSMENTS/gap-{YYYY-MM-DD}.md` + matris güncelleme önerisi
