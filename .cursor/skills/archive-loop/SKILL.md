# Archive Loop

## When to use
`/arsivle` veya kampanya kapanışı.

## Steps
1. BRIEFS + SCENARIOS + CANVA_OPS + QA topla
2. `ARCHIVE/{YYYY-MM}/{slug}/` oluştur
3. manifest.md yaz
4. BILGI_TABANI + AUDIT_LOG satırı
5. STATE.md aktif iş sıfırla
